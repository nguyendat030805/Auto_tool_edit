Template bài viết

Tải template PNG từ thiết bị hoặc bấm để chọn file (mọi kích thước; hệ thống tự điều chỉnh khung chuẩn)

Nội dung bài viết chính

Comment (từ 0 đến 3, thêm hoặc xoá tuỳ ý, ô tự co giãn theo số lượng)

Tuỳ chọn

Emoji sẽ bị bỏ qua vì font không vẽ được. Chữ tự xuống dòng và tự chỉnh cỡ cho vừa ô; chữ quá dài thì ảnh được kéo cao thêm.

Xem trước (tự cập nhật khi bạn gõ)

Nhập nội dung bài viết chính để xem trước.

Tải ảnh về

1. Video nền

Kéo video vào đây hoặc bấm để chọn file (mp4, mov, webm...)

2. Bài viết chính (tuỳ chọn: hiện đầu tiên, to hơn, đọc xong thì biến mất)

Kéo ảnh bài viết chính vào đây, bấm để chọn file, hoặc Ctrl+V để dán ảnh vừa chụp
Kéo file audio đọc bài viết vào đây

3. Ảnh comment (3-4 ảnh, theo thứ tự xuất hiện)

Kéo ảnh comment vào đây, bấm để chọn nhiều ảnh, hoặc Ctrl+V để dán ảnh vừa chụp (dán nhiều lần để thêm nhiều ảnh)

4. Giọng đọc

Kéo các file audio vào đây (tự gán theo thứ tự tên file: a1, a2, a3...)

5. Tuỳ chỉnh video

Kéo file tiếng hiệu ứng vào đây (mp3, wav...)

6. Nhạc nền (tuỳ chọn, tự lặp cho vừa độ dài video)

Kéo file nhạc nền vào đây (mp3, wav...) hoặc bấm để chọn
